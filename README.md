# Интернет-магазин «Web-Larёk»
«Web-Larёk» — это интернет-магазин с товарами для веб-разработчиков, где пользователи могут просматривать товары, добавлять их в корзину и оформлять заказы. Сайт предоставляет удобный интерфейс с модальными окнами для просмотра деталей товаров, управления корзиной и выбора способа оплаты, обеспечивая полный цикл покупки с отправкой заказов на сервер.

## Архитектура приложения

Код приложения разделен на слои согласно парадигме MVP (Model-View-Presenter), которая обеспечивает четкое разделение ответственности между классами слоев Model и View. Каждый слой несет свой смысл и ответственность:

Model - слой данных, отвечает за хранение и изменение данных.  
View - слой представления, отвечает за отображение данных на странице.  
Presenter - презентер содержит основную логику приложения и  отвечает за связь представления и данных.

Взаимодействие между классами обеспечивается использованием событийно-ориентированного подхода. Модели и Представления генерируют события при изменении данных или взаимодействии пользователя с приложением, а Презентер обрабатывает эти события используя методы как Моделей, так и Представлений.

### Базовый код

#### Класс Component
Является базовым классом для всех компонентов интерфейса.
Класс является дженериком и принимает в переменной `T` тип данных, которые могут быть переданы в метод `render` для отображения.

Конструктор:  
`constructor(container: HTMLElement)` - принимает ссылку на DOM элемент за отображение, которого он отвечает.

Поля класса:  
`container: HTMLElement` - поле для хранения корневого DOM элемента компонента.

Методы класса:  
`render(data?: Partial<T>): HTMLElement` - Главный метод класса. Он принимает данные, которые необходимо отобразить в интерфейсе, записывает эти данные в поля класса и возвращает ссылку на DOM-элемент. Предполагается, что в классах, которые будут наследоваться от `Component` будут реализованы сеттеры для полей с данными, которые будут вызываться в момент вызова `render` и записывать данные в необходимые DOM элементы.  
`setImage(element: HTMLImageElement, src: string, alt?: string): void` - утилитарный метод для модификации DOM-элементов `<img>`


#### Класс Api
Содержит в себе базовую логику отправки запросов.

Конструктор:  
`constructor(baseUrl: string, options: RequestInit = {})` - В конструктор передается базовый адрес сервера и опциональный объект с заголовками запросов.

Поля класса:  
`baseUrl: string` - базовый адрес сервера  
`options: RequestInit` - объект с заголовками, которые будут использованы для запросов.

Методы:  
`get(uri: string): Promise<object>` - выполняет GET запрос на переданный в параметрах ендпоинт и возвращает промис с объектом, которым ответил сервер  
`post(uri: string, data: object, method: ApiPostMethods = 'POST'): Promise<object>` - принимает объект с данными, которые будут переданы в JSON в теле запроса, и отправляет эти данные на ендпоинт переданный как параметр при вызове метода. По умолчанию выполняется `POST` запрос, но метод запроса может быть переопределен заданием третьего параметра при вызове.  
`handleResponse(response: Response): Promise<object>` - защищенный метод проверяющий ответ сервера на корректность и возвращающий объект с данными полученный от сервера или отклоненный промис, в случае некорректных данных.

#### Класс EventEmitter
Брокер событий реализует паттерн "Наблюдатель", позволяющий отправлять события и подписываться на события, происходящие в системе. Класс используется для связи слоя данных и представления.

Конструктор класса не принимает параметров.

Поля класса:  
`_events: Map<string | RegExp, Set<Function>>)` -  хранит коллекцию подписок на события. Ключи коллекции - названия событий или регулярное выражение, значения - коллекция функций обработчиков, которые будут вызваны при срабатывании события.

Методы класса:  
`on<T extends object>(event: EventName, callback: (data: T) => void): void` - подписка на событие, принимает название события и функцию обработчик.  
`emit<T extends object>(event: string, data?: T): void` - инициализация события. При вызове события в метод передается название события и объект с данными, который будет использован как аргумент для вызова обработчика.  
`trigger<T extends object>(event: string, context?: Partial<T>): (data: T) => void` - возвращает функцию, при вызове которой инициализируется требуемое в параметрах событие с передачей в него данных из второго параметра.


## Данные

### Интерфейсы данных

#### IProduct

Интерфейс описывает структуру товара, доступного в каталоге магазина.

```typescript
interface IProduct {
  id: string;              // Уникальный идентификатор товара
  description: string;     // Описание товара
  image: string;           // Путь к изображению товара
  title: string;           // Название товара
  category: string;        // Категория товара
  price: number | null;    // Цена товара в синапсах (может быть null для тк товар не имеет цену)
}
```

#### IBuyer

Интерфейс описывает структуру данных покупателя, необходимых для оформления заказа.

```typescript
interface IBuyer {
  payment: TPayment;  // Способ оплаты ('card'|'cash')
  email: string;      // Email адрес покупателя
  phone: string;      // Номер телефона покупателя
  address: string;    // Адрес доставки
}
```

#### TPayment

Тип для способа оплаты:

```typescript
type TPayment = 'card' | 'cash';
```

## Модели данных

### Класс CatalogModel

**Назначение и зона ответственности:**  

Отвечает за хранение и управление данными о товарах в каталоге. Хранящий полный список доступных товаров и информацию о товаре, выбранном для расширенного просмотра. Генерирует события при изменении данных каталога.

**Конструктор:**  

`constructor(events: IEvents)` - принимает экземпляр EventEmitter для генерации событий при изменении данных.

**Поля класса:**

Поле: _products
Тип: IProduct[]
Описание: Массив всех товаров, доступных в каталоге

Поле: _preview
Тип: IProduct | null
Описание: Товар, выбранный для подробного отображения в модальном окне

Поле: events
Тип: IEvents
Описание: Экземпляр EventEmitter для генерации событий

**Методы класса:**

`setProducts(products: IProduct[]): void`  
Параметры: `products` (тип: `IProduct[]`) — массив товаров, полученный с сервера.  
Описание: Сохраняет массив товаров в модель и генерирует событие `items:changed`.  
Возвращаемое значение: нет.

`getProducts(): IProduct[]`  
Параметры: нет.  
Описание: Возвращает массив всех товаров из каталога.  
Возвращаемое значение: `IProduct[]` — массив товаров.

`getProductById(id: string): IProduct | undefined`  
Параметры: `id` (тип: `string`) — уникальный идентификатор товара.  
Описание: Ищет и возвращает товар по его идентификатору.  
Возвращаемое значение: `IProduct | undefined` — найденный товар или `undefined`, если товар не найден.

`setPreview(product: IProduct): void`  
Параметры: `product` (тип: `IProduct`) — товар для подробного отображения.  
Описание: Сохраняет товар как выбранный для просмотра и генерирует событие `preview:changed`.  
Возвращаемое значение: нет.

`getPreview(): IProduct | null`  
Параметры: нет.  
Описание: Возвращает товар, выбранный для подробного просмотра.  
Возвращаемое значение: `IProduct | null` — выбранный товар или `null`, если ничего не выбрано.


### Класс BasketModel

**Назначение и зона ответственности:**  
Отвечает за управление товарами, добавленными в корзину. Хранит массив выбранных товаров, предоставляет методы для добавления и удаления товаров, расчета стоимости и количества. Генерирует события при изменении содержимого корзины.

**Конструктор:**  
`constructor(events: IEvents)` - принимает экземпляр EventEmitter для генерации событий при изменении корзины.

**Поля класса:**

Поле: _items
Тип: IProduct[]
Описание: Массив товаров, добавленных в корзину

Поле: events
Тип: IEvents
Описание: Экземпляр EventEmitter для генерации событий

**Методы класса:**

`getItems(): IProduct[]`  
Параметры: нет.  
Описание: Возвращает массив всех товаров, находящихся в корзине.  
Возвращаемое значение: `IProduct[]` — массив товаров в корзине.

`addItem(product: IProduct): void`  
Параметры: `product` (тип: `IProduct`) — товар для добавления в корзину.  
Описание: Добавляет товар в корзину и генерирует событие `basket:changed`.  
Возвращаемое значение: нет.

`removeItem(productId: string): void`  
Параметры: `productId` (тип: `string`) — идентификатор товара для удаления.  
Описание: Удаляет товар из корзины по его идентификатору и генерирует событие `basket:changed`.  
Возвращаемое значение: нет.

`clear(): void`  
Параметры: нет.  
Описание: Полностью очищает корзину и генерирует событие `basket:changed`.  
Возвращаемое значение: нет.

`getTotal(): number`  
Параметры: нет.  
Описание: Вычисляет и возвращает общую стоимость всех товаров в корзине. Товары с ценой `null` не учитываются.  
Возвращаемое значение: `number` — общая стоимость в синапсах.

`getCount(): number`  
Параметры: нет.  
Описание: Возвращает количество товаров в корзине.  
Возвращаемое значение: `number` — количество товаров.

`hasItem(productId: string): boolean`  
Параметры: `productId` (тип: `string`) — идентификатор товара для проверки.  
Описание: Проверяет наличие товара в корзине по его идентификатору.  
Возвращаемое значение: `boolean` — `true`, если товар в корзине или же `false`.


### Класс BuyerModel

**Назначение и зона ответственности:**  
Отвечает за хранение и управление данными покупателя, необходимыми для оформления заказа. Хранит информацию о способе оплаты, адресе доставки, телефоне и email. Предоставляет методы для сохранения данных, их получения, очистки и валидации. Генерирует события при изменении данных покупателя.

**Конструктор:**  

`constructor(events: IEvents)` - принимает экземпляр EventEmitter для генерации событий при изменении данных.

**Поля класса:**

Поле: _payment
Тип: TPayment | null
Описание: Выбранный способ оплаты ('card' или 'cash'), null если не выбран

Поле: _email
Тип: string
Описание: Email адрес покупателя

Поле: _phone
Тип: string
Описание: Номер телефона покупателя

Поле: _address
Тип: string
Описание: Адрес доставки

Поле: events
Тип: IEvents
Описание: Экземпляр EventEmitter для генерации событий


**Методы класса:**

`setData(data: Partial<IBuyer>): void`  
Параметры: `data` (тип: `Partial<IBuyer>`) - объект с данными для сохранения. Может содержать любое подмножество полей покупателя.  
Описание: Сохраняет переданные данные в модель. Позволяет обновить только отдельные поля без удаления значений других полей. Генерирует событие `buyer:changed`.  
Возвращаемое значение: нет.

`getData(): IBuyer`  
Параметры: нет.  
Описание: Возвращает все данные покупателя в виде объекта, соответствующего интерфейсу IBuyer.  
Возвращаемое значение: `IBuyer` - объект с данными покупателя.

`clear(): void`  
Параметры: нет.  
Описание: Очищает все данные покупателя (устанавливает все поля в пустые значения или `null`). Генерирует событие `buyer:changed`.  
Возвращаемое значение: нет.

`validate(): Record<string, string>`  
Параметры: нет.  
Описание: Проверяет валидность всех полей покупателя. Возвращает объект, содержащий ошибки валидации. Правило валидации: поле считается невалидным, если оно пустое (пустая строка, `null` или `undefined`). Если поле валидно, соответствующее свойство в объекте ошибок отсутствует.  
Возвращаемое значение: `Record<string, string>` - объект, где ключи - названия полей с ошибками, значения - текст ошибки. Если все поля валидны, возвращается пустой объект.

Пример возвращаемого значения при наличии ошибок:
```typescript
{
  payment: 'Не выбран вид оплаты',
  email: 'Укажите email',
  phone: 'Укажите телефон',
  address: 'Укажите адрес доставки'
}
```

Пример возвращаемого значения при отсутствии ошибок:
```typescript
{}
```

## Слой коммуникации

### Класс WebLarekApi

Отвечает за обмен данными с сервером «Веб-ларёк». Реализован через композицию: 
принимает в конструктор объект, реализующий интерфейс `IApi`, и через его методы 
`get` и `post` выполняет запросы к нужным эндпоинтам.

Конструктор:
`constructor(api: IApi)` - принимает экземпляр класса, реализующего `IApi` (например, базовый `Api`).

Поля:
`api: IApi` - объект, через который выполняются HTTP-запросы.

Методы:
`getProducts(): Promise<IProductsResponse>` - GET-запрос на `/product/`. 
Возвращает объект с общим количеством товаров (`total`) и массивом товаров (`items`), 
который затем передаётся в модель `Products`.
`postOrder(order: IOrderRequest): Promise<IOrderResponse>` - POST-запрос на `/order/`. 
Передаёт данные покупателя, сумму и список id товаров из модели `Order`. 
Возвращает объект с идентификатором заказа (`id`) и списанной суммой (`total`).
